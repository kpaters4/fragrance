Fragrance note analysis and similarity search

How it works: type in the notes of a scent you like (e.g. "sandalwood, iris, leather, musk"), separated by commas, and hit Analyze. We compare that note list against a corpus of perfumes and return the closest matches, weighted so rarer notes count more than common ones.
